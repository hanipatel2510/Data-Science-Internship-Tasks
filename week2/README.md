# Week 2: Exploratory Data Analysis and Visualization

## Project Title
Titanic Exploratory Data Analysis

## Objective

The objective of this project is to perform Exploratory Data Analysis (EDA) and visualization on the cleaned Titanic dataset using Python.

The analysis focuses on understanding the dataset, identifying patterns, exploring relationships between variables, and generating meaningful insights through data visualization.

## Dataset

The project uses the cleaned Titanic dataset from Week 1.

The dataset contains passenger information such as:

- PassengerId
- Survived
- Pclass
- Name
- Sex
- Age
- SibSp
- Parch
- Ticket
- Fare
- Embarked

## Exploratory Data Analysis

The following analysis was performed:

- Dataset overview
- Statistical analysis
- Survival count analysis
- Gender and survival analysis
- Passenger class and survival analysis
- Age distribution analysis
- Fare distribution analysis
- Correlation analysis

## Visualizations

The following visualizations were created:

1. Survival Count Plot
2. Gender vs Survival Plot
3. Passenger Class vs Survival Plot
4. Age Distribution
5. Fare Distribution
6. Correlation Heatmap

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn

## Conclusion

This project helped in understanding the Titanic dataset through Exploratory Data Analysis and visualization.

The analysis identified important patterns related to passenger survival, gender, passenger class, age, and fare.

The visualizations made it easier to understand relationships and patterns within the dataset and provided useful insights for future data analysis.
